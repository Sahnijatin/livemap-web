How it works

Up and running in a minute.

Run these in the project your agent works on.

1

Install

One package from npm. Or skip this and use npx.

$npm i -g livemap
2

Connect your agent

Adds small hooks for the coding agents it finds, so LiveMap hears every prompt and tool call.

$livemap init
3

Start and build

Opens LiveMap in your browser. Then work with your agent as usual and watch it build.

$livemap

Needs Node 20 or later. Works on macOS, Windows and Linux.

FAQ

Questions, answered.

Which coding agents does it work with?
LiveMap connects through hooks to Claude Code, Codex CLI and Cursor, so it sees their prompts, messages and tool calls. Any other tool still shows up through the file changes it makes, and cloud builders can be followed through git with livemap --pull.
Does my code leave my machine?
No. LiveMap runs entirely on your machine and its server only listens on your own computer. History stays in ~/.livemap, and from .env files it keeps only the key names, never the values. Plain-English summaries are optional; if you turn them on, code goes only to the AI provider you choose.
Is it free?
Yes. LiveMap is free to use, including at work and for commercial projects. It is not open source.
Do I have to change how I work?
No. Start LiveMap once in your project and keep working with your agent as you do today. LiveMap watches in the background and records the session as it goes.
Can I share a session with my team?
Yes. livemap export writes the whole session as one HTML file that anyone can open offline, like the live demo on this site. Add --no-code to leave out file contents and diffs.
Can I stop the agent when something looks wrong?
Yes. Flag a file or the whole project with a note, or pause the agent from the toolbar. The agent gets your note at its next tool call.
